## Program

質問文で提示された **DB 設計** と **フォルダー構成** をそのまま踏襲しつつ、**セキュリティ**（PDO + プリペアドステートメント、パスワードハッシュ、CSRF トークン、セッション管理）や **可読性**（Model‑View‑Controller パターン）にも配慮しています。

## 1️⃣ MySQL 用 DDL（テーブル作成・インデックス）

```sql
-- -------------------------------------------------
-- データベース作成（まだ無い場合）
-- -------------------------------------------------
CREATE DATABASE IF NOT EXISTS library CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE library;

-- -------------------------------------------------
-- users テーブル
-- -------------------------------------------------
CREATE TABLE IF NOT EXISTS users (
    id               INT UNSIGNED NOT NULL AUTO_INCREMENT,
    name             VARCHAR(100)   NOT NULL,
    email            VARCHAR(255)   NOT NULL UNIQUE,
    password_hash    CHAR(60)       NOT NULL,
    created_at       DATETIME       NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- -------------------------------------------------
-- books テーブル
-- -------------------------------------------------
CREATE TABLE IF NOT EXISTS books (
    id         INT UNSIGNED NOT NULL AUTO_INCREMENT,
    title      VARCHAR(255) NOT NULL,
    author     VARCHAR(255) NOT NULL,
    isbn       VARCHAR(20)  NOT NULL UNIQUE,
    stock      INT UNSIGNED NOT NULL DEFAULT 0,
    total      INT UNSIGNED NOT NULL DEFAULT 0,
    PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- -------------------------------------------------
-- loans テーブル
-- -------------------------------------------------
CREATE TABLE IF NOT EXISTS loans (
    id         INT UNSIGNED NOT NULL AUTO_INCREMENT,
    user_id    INT UNSIGNED NOT NULL,
    book_id    INT UNSIGNED NOT NULL,
    loan_date  DATE NOT NULL,
    due_date   DATE NOT NULL,
    return_date DATE NULL,
    status     ENUM('borrowed','returned') NOT NULL DEFAULT 'borrowed',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (id),

    -- 外部キー
    CONSTRAINT fk_loans_user FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    CONSTRAINT fk_loans_book FOREIGN KEY (book_id) REFERENCES books(id) ON DELETE CASCADE,

    -- インデックス
    INDEX idx_user_id   (user_id),
    INDEX idx_book_id   (book_id),
    INDEX idx_status    (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

* **インデックス** は `users.email`, `books.isbn`, `loans.user_id`, `loans.book_id` が自動生成されます（上記 `UNIQUE` や `FOREIGN KEY` が自動でインデックス化）。  
* 必要なら `EXPLAIN` でクエリプランを確認してください。

## 2️⃣ `config.php` – DB 接続・共通設定

```php
<?php
// -----------------------------------------------------
// config.php
// -----------------------------------------------------
declare(strict_types=1);

// ---------- 1. 基本設定 ----------
define('APP_ROOT', __DIR__);
define('BASE_URL', 'http://' . $_SERVER['HTTP_HOST'] . rtrim(dirname($_SERVER['PHP_SELF']), '/\\') . '/');

// ---------- 2. データベース接続 ----------
$dsn = 'mysql:host=localhost;dbname=library;charset=utf8mb4';
$dbUser = 'root';                 // ← 環境に合わせて変更
$dbPass = '';                     // ← 環境に合わせて変更

try {
    $pdo = new PDO($dsn, $dbUser, $dbPass, [
        PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
        PDO::ATTR_EMULATE_PREPARES   => false,
    ]);
} catch (PDOException $e) {
    http_response_code(500);
    exit('Database connection failed.');
}

// ---------- 3. セッション ----------
session_start();

// ---------- 4. CSRF トークン ----------
if (empty($_SESSION['csrf'])) {
    $_SESSION['csrf'] = bin2hex(random_bytes(32));
}
function csrf_token(): string {
    return $_SESSION['csrf'];
}

// ---------- 5. エラーハンドラ ----------
set_error_handler(function ($severity, $message, $file, $line) {
    if (error_reporting() & $severity) {
        // 開発環境のみ詳細表示
        echo "<pre>";
        echo "Error: [$severity]\n";
        echo "Message: $message\n";
        echo "File: $file\n";
        echo "Line: $line\n";
        echo "</pre>";
        exit;
    }
});
?>
```

### ポイント

| 項目 | 説明 |
|------|------|
| `PDO::ATTR_EMULATE_PREPARES = false` | 実際のプリペアドステートメントを使用し、SQL インジェクション対策を徹底 |
| `csrf_token()` | POST フォームに埋め込むトークン取得関数 |
| `session_start()` | 認証情報はサーバ側セッションに保存 |
| `BASE_URL` | フロントエンドからの相対パス計算に便利 |

## 3️⃣ `functions.php` – ユーティリティ関数

```php
<?php
// -----------------------------------------------------
// functions.php
// -----------------------------------------------------
declare(strict_types=1);

// ---------- 1. パスワードハッシュ ----------
use PDO;

/**
 * パスワードを bcrypt ハッシュ化
 *
 * @param string $rawPassword 平文パスワード
 * @return string ハッシュ文字列
 */
function hash_password(string $rawPassword): string
{
    return password_hash($rawPassword, PASSWORD_BCRYPT);
}

/**
 * パスワード検証
 *
 * @param string $rawPassword 入力された平文
 * @param string $hashedPassword DB に保存されたハッシュ
 * @return bool true なら一致
 */
function verify_password(string $rawPassword, string $hashedPassword): bool
{
    return password_verify($rawPassword, $hashedPassword);
}

// ---------- 2. リダイレクト ----------
/**
 * 指定 URL へリダイレクト（GET パラメータは保持しない）
 */
function redirect(string $url): void
{
    header('Location: ' . $url);
    exit;
}

// ---------- 3. 入力バリデーション ----------
/**
 * 基本的なメール形式チェック
 */
function is_valid_email(string $email): bool
{
    return filter_var($email, FILTER_VALIDATE_EMAIL) !== false;
}

/**
 * 簡易バリデーション結果オブジェクト
 */
class ValidationResult
{
    public array $errors = [];

    public function add(string $field, string $msg): void
    {
        $this->errors[$field] = $msg;
    }

    public function isValid(): bool
    {
        return empty($this->errors);
    }
}

/**
 * バリデーション実行（登録画面用）
 */
function validate_registration(array $data, ValidationResult $result): void
{
    $result->errors = [];

    if (empty($data['name'])) {
        $result->add('name', '名前は必須です。');
    }
    if (!is_valid_email($data['email'])) {
        $result->add('email', '有効なメールアドレスを入力してください。');
    } elseif (strlen($data['email']) > 255) {
        $result->add('email', 'メールアドレスが長すぎます。');
    }
    if (empty($data['password'])) {
        $result->add('password', 'パスワードは必須です。');
    } elseif (strlen($data['password']) < 6) {
        $result->add('password', 'パスワードは6文字以上で入力してください。');
    }
}
?>
```

### 4‑1 `models/User.php`

```php
<?php
// -----------------------------------------------------
// models/User.php
// -----------------------------------------------------
declare(strict_types=1);

class User
{
    private int $id;
    private string $name;
    private string $email;
    private string $passwordHash;

    public function __construct(int $id, string $name, string $email, string $passwordHash)
    {
        $this->id = $id;
        $this->name = $name;
        $this->email = $email;
        $this->passwordHash = $passwordHash;
    }

    // ----- getter -----
    public function getId(): int { return $this->id; }
    public function getName(): string { return $this->name; }
    public function getEmail(): string { return $this->email; }
    public function getPasswordHash(): string { return $this->passwordHash; }

    // ----- static CRUD -----
    public static function findById(int $id, PDO $pdo): ?self
    {
        $stmt = $pdo->prepare('SELECT id, name, email, password_hash FROM users WHERE id = :id');
        $stmt->execute(['id' => $id]);
        $row = $stmt->fetch();
        return $row ? new self($row['id'], $row['name'], $row['email'], $row['password_hash']) : null;
    }

    public static function findByEmail(string $email, PDO $pdo): ?self
    {
        $stmt = $pdo->prepare('SELECT id, name, email, password_hash FROM users WHERE email = :email');
        $stmt->execute(['email' => $email]);
        $row = $stmt->fetch();
        return $row ? new self($row['id'], $row['name'], $row['email'], $row['password_hash']) : null;
    }

    public static function create(array $data, PDO $pdo): ?self
    {
        $hash = hash_password($data['password']);
        $stmt = $pdo->prepare('INSERT INTO users (name, email, password_hash) VALUES (:name, :email, :hash)');
        $stmt->execute([
            'name'  => $data['name'],
            'email' => $data['email'],
            'hash'  => $hash,
        ]);
        $id = (int)$pdo->lastInsertId();
        return new self($id, $data['name'], $data['email'], $hash);
    }

    // パスワード更新（必要なら）
    public function updatePassword(string $newRawPwd, PDO $pdo): void
    {
        $hash = hash_password($newRawPwd);
        $stmt = $pdo->prepare('UPDATE users SET password_hash = :hash WHERE id = :id');
        $stmt->execute(['hash' => $hash, 'id' => $this->id]);
    }
}
?>
```

```php
        return $row ? new self($row['id'], $row['title'], $row['author'], $row['isbn'],
                               $row['stock'], $row['total']) : null;
    }

    public static function create(array $data, PDO $pdo): ?self
    {
        $stmt = $pdo->prepare('INSERT INTO books (title, author, isbn, stock, total) 
                              VALUES (:title, :author, :isbn, :stock, :total)');
        $stmt->execute([
            'title'  => $data['title'],
            'author' => $data['author'],
            'isbn'   => $data['isbn'],
            'stock'  => $data['stock'] ?? 0,
            'total'  => $data['total'] ?? 0,
        ]);
        $id = (int)$pdo->lastInsertId();
        return new self($id, $data['title'], $data['author'], $data['isbn'],
                        $data['stock'] ?? 0, $data['total'] ?? 0);
    }

    // 在庫増減（入庫・出庫） ------------------------------------
    public function increaseStock(int $qty, PDO $pdo): void
    {
```

### 4‑3 `models/Loan.php`

```php
<?php
// -----------------------------------------------------
// models/Loan.php
// -----------------------------------------------------
declare(strict_types=1);

class Loan
{
    private int $id;
    private int $userId;
    private int $bookId;
    private string $loanDate;   // YYYY-MM-DD
    private string $dueDate;    // YYYY-MM-DD
    private ?string $returnDate = null;
    private string $status;    // 'borrowed' or 'returned'

    public function __construct(
        int $id,
        int $userId,
        int $bookId,
        string $loanDate,
        string $dueDate,
        ?string $returnDate = null,
        string $status = 'borrowed'
    ) {
        $this->id         = $id;
        $this->userId     = $userId;
        $this->bookId     = $bookId;
        $this->loanDate   = $loanDate;
        $this->dueDate    = $dueDate;
        $this->returnDate = $returnDate;
        $this->status     = $status;
    }

    // getters -------------------------------------------------
    public function getId(): int { return $this->id; }
    public function getUserId(): int { return $this->userId; }
    public function getBookId(): int { return $this->bookId; }
    public function getLoanDate(): string { return $this->loanDate; }
    public function getDueDate(): string { return $this->dueDate; }
    public function getReturnDate(): ?string { return $this->returnDate; }
    public function getStatus(): string { return $this->status; }

    // static CRUD ---------------------------------------------
    public static function findById(int $id, PDO $pdo): ?self
    {
        $stmt = $pdo->prepare('SELECT id, user_id, book_id, loan_date, due_date, return_date, status 
                              FROM loans WHERE id = :id');
        $stmt->execute(['id' => $id]);
        $row = $stmt->fetch();
        return $row ? new self(
            $row['id'],
            $row['user_id'],
            $row['book_id'],
            $row['loan_date'],
            $row['due_date'],
            $row['return_date'],
            $row['status']
        ) : null;
    }

    public static function findByUserId(int $userId, PDO $pdo): array
    {
        $stmt = $pdo->prepare('SELECT id, user_id, book_id, loan_date, due_date, return_date, status 
                              FROM loans WHERE user_id = :uid AND status = "borrowed"');
        $stmt->execute(['uid' => $userId]);
        return $stmt->fetchAll(); // array of Loan objects
    }

    public static function findByBookId(int $bookId, PDO $pdo): array
    {
        $stmt = $pdo->prepare('SELECT id, user_id, book_id, loan_date, due_date, return_date, status 
                              FROM loans WHERE book_id = :bid AND status = "borrowed"');
        $stmt->execute(['bid' => $bookId]);
        return $stmt->fetchAll();
    }

    public static function createBorrow(int $userId, int $bookId, PDO $pdo, int $days = 14): self
    {
        // 貸出日
        $loanDate = date('Y-m-d');
        // 返却期限（今日から $days 日後）
        $dueDate = (date('Y-m-d') . ' +' . $days . ' days');

        $stmt = $pdo->prepare('INSERT INTO loans (user_id, book_id, loan_date, due_date, status) 
                              VALUES (:uid, :bid, :ld, :dd, "borrowed")');
        $stmt->execute([
            'uid' => $userId,
            'bid' => $bookId,
            'ld'  => $loanDate,
            'dd'  => $dueDate,
        ]);
        $id = (int)$pdo->lastInsertId();

        // 在庫減算
        $book = Book::findById($bookId, $pdo);
        $book->decreaseStock(1, $pdo);

        return new self($id, $userId, $bookId, $loanDate, $dueDate, null, 'borrowed');
    }

    public static function createReturn(int $loanId, PDO $pdo): self
    {
        $stmt = $pdo->prepare('UPDATE loans SET return_date = :rd, status = "returned" 
                              WHERE id = :lid');
        $stmt->execute([
            'rd' => date('Y-m-d'),
            'lid'=> $loanId,
        ]);

        // 在庫加算
        $loan = self::findById($loanId, $pdo);
        $book = Book::findById($loan->getBookId(), $pdo);
        $book->increaseStock(1, $pdo);

        return new self($loanId, $loan->getUserId(), $loan->getBookId(),
                        $loan->getLoanDate(), $loan->getDueDate(),
                        date('Y-m-d'), 'returned');
    }
}
?>
```

## 5️⃣ Router & エントリーポイント `index.php`

```php
<?php
// -----------------------------------------------------
// public/index.php
// -----------------------------------------------------
declare(strict_types=1);

require_once __DIR__ . '/../config.php';
require_once __DIR__ . '/../models/User.php';
require_once __DIR__ . '/../models/Book.php';
require_once __DIR__ . '/../models/Loan.php';
require_once __DIR__ . '/../controllers/RegisterController.php';
require_once __DIR__ . '/../controllers/BookInController.php';
require_once __DIR__ . '/../controllers/SearchController.php';
require_once __DIR__ . '/../controllers/LoanController.php';
require_once __DIR__ . '/../controllers/ReturnController.php';
require_once __DIR__ . '/../controllers/HistoryController.php';

// -----------------------------------------------
// 認証状態取得ユーティリティ
// -----------------------------------------------
function getCurrentUser(): ?User
{
    if (!isset($_SESSION['user_id'])) {
        return null;
    }
    $uid = (int)$_SESSION['user_id'];
    return User::findById($uid, $GLOBALS['pdo']);
}

// -----------------------------------------------
// ルーティング
// -----------------------------------------------
$method = $_SERVER['REQUEST_METHOD'];
$uri    = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);

// ルートページはログイン済みかどうかで分岐
if ($uri === '/' || $uri === '/home') {
    $user = getCurrentUser();
    if ($user) {
        // ホーム画面（マイページ）へ
        require_once __DIR__ . '/views/home.php';
    } else {
        // 未ログイン → ログインページへリダイレクト
        redirect(BASE_URL . 'login.php');
    }
} else {
    // 以降のパスはコントローラに委譲
    $parts = explode('/', trim($uri, '/'));

    // 認証が必要なコントローラは先頭に 'auth_' を付与
    if (in_array($parts[0], ['register', 'book_in', 'search', 'loan', 'return', 'history'])) {
        // ログインチェック
        if (!getCurrentUser()) {
            redirect(BASE_URL . 'login.php');
        }
    }

    // コントローラ呼び出し
    switch ($parts[0]) {
        case 'register':
            require_once __DIR__ . '/controllers/RegisterController.php';
            break;
        case 'book_in':
            require_once __DIR__ . '/controllers/BookInController.php';
            break;
        case 'search':
            require_once __DIR__ . '/controllers/SearchController.php';
            break;
        case 'loan':
            require_once __DIR__ . '/controllers/LoanController.php';
            break;
        case 'return':
            require_once __DIR__ . '/controllers/ReturnController.php';
            break;
        case 'history':
            require_once __DIR__ . '/controllers/HistoryController.php';
            break;
        case 'login':
            if ($method === 'GET') {
                require_once __DIR__ . '/views/login.php';
            } else {
                // POST → 認証処理
                $email = $_POST['email'] ?? '';
                $pass  = $_POST['password'] ?? '';
                $user  = User::findByEmail($email, $GLOBALS['pdo']);
                if ($user && verify_password($pass, $user->getPasswordHash())) {
                    $_SESSION['user_id'] = $user->getId();
                    redirect(BASE_URL . 'home.php');
                } else {
                    echo '<p style="color:red;">メールアドレスまたはパスワードが違います。</p>';
                    require_once __DIR__ . '/views/login.php';
                }
            }
            break;
        case 'logout':
            session_destroy();
            redirect(BASE_URL . 'login.php');
            break;
        default:
            http_response_code(404);
            echo '<h1>404 Not Found</h1>';
    }
}
```

> **ポイント**
> * `$GLOBALS['pdo']` は `config.php` で定義した PDO インスタンスです。  
> * 認証が必要なページは `getCurrentUser()` が `null` の場合にリダイレクト。  
> * `parse_url()` でパスだけ抽出し、シンプルなディスパッチャを実装。
